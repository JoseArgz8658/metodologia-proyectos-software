# Checklist de revisión — Fase 2

## Visual

- [ ] Tema claro correcto.
- [ ] Tema oscuro correcto.
- [ ] Jerarquía tipográfica clara.
- [ ] Colores de estado distinguibles.
- [ ] Espaciado consistente.

## Responsive

- [ ] Móvil 320–430 px.
- [ ] Tablet alrededor de 768 px.
- [ ] Escritorio 1366 px.
- [ ] Pantalla grande 1920 px o superior.
- [ ] Tabla contenida con desplazamiento horizontal.

## Interacciones

- [ ] Menú móvil abre y cierra.
- [ ] Selector de tema persiste tras recargar.
- [ ] Modal abre, cierra, cancela y confirma.
- [ ] Toast aparece y desaparece.

## Accesibilidad

- [ ] Navegación completa con teclado.
- [ ] Foco visible.
- [ ] Enlace para saltar al contenido.
- [ ] Etiquetas y errores de formulario comprensibles.
- [ ] Modal cerrable con Escape.
- [ ] Zoom al 200 % sin pérdida funcional.
- [ ] Movimiento reducido respetado.

## Documentación

- [ ] Tokens documentados.
- [ ] Componentes documentados.
- [ ] Accesibilidad documentada.
- [ ] Plan de pruebas disponible.
- [ ] Alcance futuro claramente separado.
