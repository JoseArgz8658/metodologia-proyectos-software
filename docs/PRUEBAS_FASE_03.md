# Plan de pruebas — Fase 3

## Pruebas documentales

- Verificar que las doce etapas del ciclo de vida estén completas y ordenadas.
- Confirmar que cada etapa tenga una salida verificable.
- Revisar que Ready y Done no se contradigan.
- Validar que los artefactos mínimos cubran inicio, producto, arquitectura, ejecución, calidad, entrega y cierre.
- Confirmar que la adaptación por tamaño mantenga decisiones críticas.

## Pruebas visuales

Abrir `metodologia.html` y revisar:

- 320 px: sin desbordamientos horizontales no intencionales.
- 768 px: tarjetas y navegación legibles.
- 1366 px: jerarquía visual equilibrada.
- 1920 px o TV: contenido escalado y foco visible.
- Tema claro y oscuro.
- Zoom del navegador al 200 %.

## Pruebas de interacción y accesibilidad

- Navegar mediante Tab y Shift+Tab.
- Activar enlaces con Enter.
- Confirmar foco visible.
- Probar el enlace para saltar al contenido.
- Revisar orden semántico de encabezados.
- Activar reducción de movimiento del sistema.

## Resultado esperado

La metodología debe poder comprenderse y aplicarse sin conocer el proyecto que originó el repositorio y sin depender de una tecnología específica.
