# Resumen de entrega — Fase 3

## Resultado

La metodología central ya define cómo iniciar, investigar, planificar, construir, validar, publicar, operar y cerrar un proyecto de software.

## Entregables

- Ciclo de vida de doce etapas.
- Puertas de control entre etapas.
- Artefactos mínimos obligatorios.
- Definition of Ready y Definition of Done.
- Adaptación por tamaño y riesgo.
- Roles y responsabilidades.
- Git Flow oficial.
- Vista visual `metodologia.html`.
- Checklist de revisión.

## Validación recomendada

1. Leer el ciclo como si se aplicara a un proyecto nuevo.
2. Confirmar que cada etapa produce evidencia útil.
3. Revisar el nivel adecuado para un proyecto pequeño, estándar y crítico.
4. Probar la página visual en móvil y escritorio.
5. Verificar navegación con teclado y temas claro/oscuro.
6. Revisar que el Git Flow coincide con la forma de trabajo por fases.

## Próxima fase

La Fase 4 convertirá esta metodología en plantillas copiables para README, fases, ADR, requisitos, riesgos, pruebas, pull requests, releases y cierre.
