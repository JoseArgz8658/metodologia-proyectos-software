# Checklist de revisión — Fase 4

## Catálogo

- [ ] Existe una guía clara de uso.
- [ ] Las plantillas están organizadas por propósito.
- [ ] Todos los campos rellenables usan corchetes.

## Proyecto y gestión

- [ ] Brief, alcance, requisitos, roadmap y fases son reutilizables.
- [ ] Riesgos incluyen responsable, disparador y respuesta.
- [ ] Los criterios de aceptación son verificables.

## Técnica y calidad

- [ ] Arquitectura cubre seguridad, datos, observabilidad y rendimiento.
- [ ] ADR permite comparar alternativas y consecuencias.
- [ ] El plan de pruebas define entrada, salida y evidencias.
- [ ] El despliegue contempla rollback explícito.

## GitHub

- [ ] El PR exige validación, evidencias y riesgos.
- [ ] Existen formatos para errores y funcionalidades.

## Kits

- [ ] El kit pequeño mantiene controles mínimos.
- [ ] El kit estándar sirve como opción profesional por defecto.
- [ ] El kit crítico agrega controles proporcionales al riesgo.

## Cierre

- [ ] No existen datos específicos de un proyecto real.
- [ ] La documentación es neutral respecto de tecnología.
- [ ] Los archivos pueden copiarse sin depender de este repositorio.
