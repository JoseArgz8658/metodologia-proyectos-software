# Metodología de Proyectos de Software

Repositorio privado y evolutivo para documentar una metodología personal de análisis, diseño, desarrollo, pruebas, despliegue y mantenimiento de proyectos de software.

## Propósito

Evitar comenzar cada proyecto desde cero. Este repositorio reunirá criterios, plantillas, decisiones, componentes y lecciones que puedan reutilizarse en proyectos móviles, web, backend y multiplataforma.

## Laboratorio visual

La raíz contiene un laboratorio UI construido con HTML, CSS y JavaScript nativos. Está preparado para publicarse mediante GitHub Pages.

## Forma de trabajo

1. Cada cambio importante se desarrolla en una rama propia.
2. Cada fase define objetivo, alcance y criterios de aceptación.
3. Los cambios se revisan mediante pull request.
4. `main` debe conservar una versión estable y documentada.
5. La experiencia obtenida debe convertirse en conocimiento reutilizable.
