# Guías tecnológicas

Este directorio reúne criterios reutilizables para seleccionar, iniciar, construir, validar y mantener soluciones de software con tecnologías concretas.

## Principio rector

La tecnología se elige después de comprender el problema, las restricciones, el equipo, la operación y el riesgo. Ninguna guía reemplaza una decisión arquitectónica documentada.

## Guías disponibles

- `SELECCION_STACK.md`: evaluación y elección de tecnologías.
- `FLUTTER_DART.md`: aplicaciones Flutter y Dart.
- `FIREBASE.md`: autenticación, datos, archivos y reglas.
- `WEB.md`: aplicaciones y sitios web.
- `APIS_REST.md`: diseño y operación de APIs.
- `PERSISTENCIA_LOCAL.md`: almacenamiento local y sincronización.
- `ANDROID_MOVIL_TV.md`: particularidades de Android móvil y TV.
- `CI_CD_GITHUB_ACTIONS.md`: automatización, validación y despliegue.

## Uso recomendado

1. Definir requisitos y restricciones.
2. Completar la matriz de selección tecnológica.
3. Registrar la decisión mediante un ADR.
4. Aplicar únicamente las guías relevantes.
5. Adaptar controles según el tamaño y criticidad del proyecto.
6. Mantener versiones, excepciones y deuda técnica documentadas.
