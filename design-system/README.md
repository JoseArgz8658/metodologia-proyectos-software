# Design System

Este directorio contiene las reglas visuales y de interacción reutilizables de la metodología.

## Documentos

- [Tokens](TOKENS.md): colores, espaciado, radios, elevación, movimiento y temas.
- [Componentes](COMPONENTES.md): variantes, estados y criterios de incorporación.
- [Accesibilidad](ACCESIBILIDAD.md): requisitos mínimos y validaciones recomendadas.

## Fuente ejecutable

El laboratorio visual disponible en `index.html` funciona como catálogo vivo del sistema. La documentación explica las reglas; el laboratorio demuestra su comportamiento.

## Principio de mantenimiento

Toda incorporación debe actualizar, como mínimo:

1. El ejemplo ejecutable.
2. La documentación del componente o token.
3. Las reglas de accesibilidad.
4. Los criterios responsive.
5. La fase o pull request correspondiente.
