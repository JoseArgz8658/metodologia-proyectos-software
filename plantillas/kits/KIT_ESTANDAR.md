# Kit estándar

Para aplicaciones móviles, web, APIs, sistemas internos y productos con integraciones o varios colaboradores.

## Copiar

- Todas las plantillas de `proyecto/`.
- `tecnico/ARQUITECTURA.md`.
- `tecnico/ADR.md` cuando exista una decisión relevante.
- `gestion/REGISTRO_RIESGOS.md`.
- Todas las plantillas de `calidad/`.
- Todas las plantillas de `github/`.

## Reglas mínimas

- Requisitos funcionales y no funcionales trazables.
- Arquitectura y riesgos revisados antes de construir.
- Roadmap dividido en fases cerrables.
- Pull request por fase.
- Pruebas y evidencias antes del merge.
- Despliegue con validación y rollback.
- Decisiones técnicas importantes registradas.

Este es el nivel recomendado por defecto para proyectos profesionales.
