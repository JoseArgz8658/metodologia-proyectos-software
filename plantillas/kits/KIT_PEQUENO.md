# Kit pequeño

Para prototipos, herramientas personales, pruebas de concepto y cambios de bajo riesgo.

## Copiar

- `proyecto/BRIEF_PROYECTO.md`
- `proyecto/ALCANCE_Y_REQUISITOS.md`
- `proyecto/ROADMAP_Y_FASES.md`
- `calidad/PLAN_PRUEBAS.md`
- `github/PULL_REQUEST_TEMPLATE.md`

## Reglas mínimas

- Alcance y exclusiones explícitos.
- Una rama por fase o cambio.
- Criterios de aceptación verificables.
- Pruebas de los flujos principales.
- README y estado del proyecto actualizados.

Escalar al kit estándar si aparecen múltiples integraciones, datos sensibles, varios colaboradores o despliegue productivo relevante.
