# Plantillas reutilizables

Esta carpeta contiene documentos base para iniciar y gobernar proyectos de software.

## Uso

1. Seleccionar el kit según el tamaño y riesgo del proyecto.
2. Copiar únicamente las plantillas necesarias al nuevo repositorio.
3. Reemplazar todos los campos entre corchetes.
4. Eliminar secciones que no correspondan, dejando registro de la decisión.
5. Mantener los documentos actualizados durante todo el ciclo de vida.

## Catálogo

- `proyecto/`: definición, alcance, requisitos y roadmap.
- `tecnico/`: arquitectura y decisiones técnicas.
- `calidad/`: pruebas, despliegue y rollback.
- `gestion/`: riesgos, fases y cierre.
- `github/`: pull requests, errores y solicitudes de funcionalidades.
- `kits/`: selección recomendada según complejidad.

Las plantillas son neutrales respecto de tecnología y deben adaptarse sin perder trazabilidad.
