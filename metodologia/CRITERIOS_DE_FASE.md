# Criterios para gestionar una fase

Toda fase debe declarar:

- Objetivo.
- Alcance incluido.
- Alcance excluido.
- Dependencias.
- Riesgos.
- Entregables.
- Criterios de aceptación.
- Pruebas.
- Evidencia esperada.
- Rama de trabajo.

## Estados

- Planificada.
- En progreso.
- Bloqueada.
- En revisión.
- Completada.

## Regla de cierre

Una fase se cierra solamente cuando sus criterios fueron verificados, la documentación refleja el resultado y el cambio fue integrado en la rama estable. Las mejoras no incluidas deben registrarse como trabajo futuro, no mantenerse ocultas dentro de una fase declarada como completa.
