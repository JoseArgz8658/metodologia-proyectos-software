# Definition of Ready y Definition of Done

## Definition of Ready

Un elemento puede iniciar desarrollo cuando:

- Su objetivo y valor están claros.
- Tiene criterios de aceptación verificables.
- Sus dependencias conocidas están resueltas o planificadas.
- Cuenta con diseño o reglas suficientes.
- Se identificaron riesgos relevantes.
- Puede dividirse y revisarse sin mezclar trabajo no relacionado.
- El responsable sabe cómo demostrarlo.

## Definition of Done

Un elemento se considera terminado cuando:

- Cumple todos sus criterios de aceptación.
- El código es legible y coherente con la arquitectura.
- Las pruebas requeridas fueron ejecutadas.
- No introduce errores conocidos bloqueantes.
- Los estados vacíos, error y carga están considerados cuando aplican.
- La interfaz fue revisada en tamaños objetivo.
- La accesibilidad mínima fue comprobada.
- La documentación afectada está actualizada.
- El PR describe alcance, pruebas y riesgos.
- El cambio fue integrado en la rama objetivo.

## Regla de excepción

Una excepción debe registrarse explícitamente con motivo, impacto, responsable y fecha o condición de resolución. “Lo arreglamos después” no constituye una decisión trazable.
