# Registro de decisiones técnicas

Las decisiones relevantes deben registrarse mediante ADR o un formato equivalente.

## Cuándo registrar una decisión

- Elección de arquitectura o patrón.
- Cambio de base de datos o proveedor.
- Integración externa importante.
- Estrategia de autenticación o seguridad.
- Decisión difícil de revertir.
- Compromiso relevante entre costo, tiempo, calidad o rendimiento.

## Contenido mínimo

- Identificador y título.
- Fecha y estado.
- Contexto.
- Opciones consideradas.
- Decisión tomada.
- Consecuencias positivas y negativas.
- Condición para revisar la decisión.

## Estados sugeridos

- Propuesto.
- Aceptado.
- Reemplazado.
- Rechazado.
- Obsoleto.

El registro no pretende justificar cada línea de código. Su objetivo es conservar el razonamiento que una persona futura no podría deducir observando solamente la implementación.
