# Checklist de inicio y cierre de proyecto

## Inicio

- [ ] Problema y propósito definidos.
- [ ] Usuarios y actores identificados.
- [ ] Alcance inicial y exclusiones registradas.
- [ ] Riesgos iniciales visibles.
- [ ] Nivel metodológico seleccionado.
- [ ] Repositorio, responsables y comunicación definidos.
- [ ] Primera fase con criterios de aceptación.

## Antes de publicar

- [ ] Requisitos prioritarios validados.
- [ ] Pruebas requeridas ejecutadas.
- [ ] Defectos conocidos registrados.
- [ ] Seguridad y configuración revisadas.
- [ ] Versión y changelog preparados.
- [ ] Despliegue y rollback documentados.

## Cierre

- [ ] Alcance entregado comparado con lo planificado.
- [ ] Deuda técnica documentada.
- [ ] Documentación operativa actualizada.
- [ ] Lecciones aprendidas registradas.
- [ ] Próximos pasos priorizados.
- [ ] Ramas temporales y artefactos ordenados.
